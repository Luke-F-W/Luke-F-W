## [Civie Data Getters](https://github.com/Luke-F-W/Civie_Data_Getters)

Civie Data Getters is the repository for Civie that manages data collection from [Lobbying.ie](https://www.lobbying.ie/) and from [the Oireachtas API](https://api.oireachtas.ie).
This repository is made with python and does many things, such as:

- Collect bills, votes from the Oireachtas API
- Merges, Cleans, Identifies bad data & Converts lobbying CSV's to Json.
- Converts Json files to [SQLite](https://sqlite.org/index.html) tables.
- Append newer data to pre existing Jsons.
- Create stats per politician based on data collected.
This is the **first** of the 3 repositories for Civie.ie

## [Civie API](https://github.com/Luke-F-W/Civie-API)

The Civie API can accept queries & return information from my [SQLite](https://sqlite.org/index.html) database that was created and populated with data from the repository above. I made it with [flask](https://flask.palletsprojects.com/en/stable/). It is a very simple API. only returning data that it receives a request for.
